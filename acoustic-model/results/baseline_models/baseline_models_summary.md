## Threshold-dependent secondary metrics (provisional - read this caveat first)

Per section 8b: each fold's Youden's-J threshold is chosen from that same fold's held-out predictions, then that same fold is scored at it. These numbers are an **optimistic upper bound** on what a single fixed threshold would achieve, not a fair estimate of one. ROC-AUC/PR-AUC/Brier above are not subject to this.

- **random_forest**: sensitivity(Youden)=0.6762 (0.0916), specificity(Youden)=0.6461 (0.1117), F1(Youden)=0.5330 (0.0350), balanced accuracy(Youden)=0.6611 (0.0358)
- **svm**: sensitivity(Youden)=0.6952 (0.1452), specificity(Youden)=0.6235 (0.1957), F1(Youden)=0.5339 (0.0176), balanced accuracy(Youden)=0.6593 (0.0269)
- **logistic_regression**: sensitivity(Youden)=0.6286 (0.1887), specificity(Youden)=0.6539 (0.1755), F1(Youden)=0.5025 (0.0397), balanced accuracy(Youden)=0.6412 (0.0214)

- **logistic_regression**: 0.2190 (0.0928)

This project has not settled whether the eventual locked threshold should prioritize sensitivity over precision (see section 8b) - this readout doesn't presuppose an answer, it's reported alongside Youden's J so that decision has more to work with when it's made.
